# Author circuits

Fulmetry uses TypeScript as the circuit authoring language. Keep the root board small and move subsystems into named modules so an agent can load and edit only the relevant context.

## Root board

```ts title="circuit/board.ts"
import { Board, Circuit } from "fulmetry";
import { addPowerIndicator } from "./components/power-indicator";

export default function createCircuit(): Circuit {
  const circuit = new Circuit();
  const board = new Board({
    width: "30mm",
    height: "20mm",
    layers: 2,
  });

  addPowerIndicator(board);
  circuit.add(board);
  return circuit;
}
```

## Composable component module

```ts title="circuit/components/power-indicator.ts"
import { Led, PinHeader, Resistor, Trace, type Board } from "fulmetry";

export function addPowerIndicator(board: Board): void {
  board.add(new Resistor({
    name: "R1",
    resistance: "1k",
    footprint: "0603",
    pcbX: -3,
    pcbY: 2,
  }));

  board.add(new Led({
    name: "D1",
    footprint: "0603",
    pcbX: 3,
    pcbY: 2,
  }));

  board.add(new PinHeader({
    name: "J1",
    pinCount: 2,
    footprint: "pinrow2_nosquareplating",
    pcbX: 0,
    pcbY: -2,
  }));

  board.add(new Trace({
    name: "VCC_RESISTOR",
    from: ".R1 > .pin2",
    to: "net.VCC",
    width: "0.2mm",
  }));
}
```

## Import compatibility

Curated authoring symbols imported from `fulmetry` and the identical supported tscircuit authoring set mean the same thing. Prefer `fulmetry` in a Fulmetry project so application code stays behind Fulmetry's facade and can tolerate future internal replacement.

## Design guidance for agents

1. Give every component and trace a stable, descriptive name.
2. Split source by subsystem or responsibility, not by arbitrary file size.
3. Use explicit dimensions, footprints, layers, and trace widths.
4. Keep geometry deterministic; do not read clocks, randomness, the network, or undeclared files during verified evaluation.
5. Build after small changes and feed structured diagnostics back into the next edit.
6. Use the inspection server for visual review, not as a second source of circuit state.

<Info>
Fine manual adjustment can happen after a detached KiCad export. Fulmetry does not claim automatic synchronization or a round trip from later KiCad edits.
</Info>
