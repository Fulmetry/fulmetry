# Evidence handoff

Keep routine handoffs compact. Include:

```text
Claim:
Requirement or diagnostic:
Source digest:
Commands and exit classifications:
Durable report paths:
Relevant status dimensions:
Tests or simulations added:
Sensitivity proof, if performed:
Physical readiness inventory, when claimed:
Preview eligibility and expected routes:
Unresolved findings:
Human decisions required:
```

Do not say only “tests pass” or “looks good.” Tie every narrow claim to an exact command and current source digest. Say explicitly when evidence is missing, stale, incomplete, unavailable, unsupported, waived, or limited to pre-compliance.

For a risk-bearing review, start from fresh context or a clean worktree when practical. Re-run the stated commands, verify report freshness, examine artifacts rather than summaries alone, and try to construct a counterexample. Accept only the stated claim; do not issue a universal board-ready judgment.
